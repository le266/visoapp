# Dashboard de Avisos Universitarios

## Descripción

Aplicación web interactiva desarrollada con HTML, CSS y JavaScript.

Permite:

- Registrar avisos
- Buscar avisos
- Filtrar por categoría
- Eliminar avisos
- Guardar datos con localStorage

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript ES6

## Funcionalidades

- Manipulación del DOM
- Eventos
- Validaciones
- Arreglos y objetos
- Métodos map() y filter()
- Persistencia localStorage

## Cómo ejecutar

Abrir el archivo:

index.html
